Website for Kreis Garage, Josh Kreis's mobile and drop-off auto service in Greater Cincinnati.

## What's here

- `index.html`: the whole site in one file, with fonts and logos built in. No build step.

## Publishing

The site is served with GitHub Pages from the `main` branch, root folder.
To update it, replace `index.html` and commit. Changes go live in a minute or two.
